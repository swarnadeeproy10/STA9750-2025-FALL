NIMBY vs YIMBY Policy Approaches

This analysis references specialized policy and industry terminology. The definitions provided below offer context for various terms and acronyms utilized throughout this document.

WarningEssential Terminology

NIMBY: ”Not In My Backyard” - resistance to proposed development and housing initiatives in residential areas that residents consider undesirable

YIMBY: ”Yes In My Backyard” - advocacy movement supporting residential development projects within local communities

Housing Crisis: ongoing deficit in affordable housing construction relative to population demand

CBSA: Core Based Statistical Area - metropolitan and micropolitan regions designated for statistical purposes

NAICS Codes: North American Industry Classification System - standardized classification framework for business categorization by sector and type

Individual Income: aggregate earnings for a single person from employment, Social Security, and supplementary benefits

Industry Wages: mean compensation provided to workers within a particular sector

Rent Burden: proportion of renters allocating more than 30% of monthly earnings toward housing and utility costs

Severe Rent Burden: proportion of renters allocating more than 50% of monthly earnings toward housing and utility costs

Housing Growth: expansion in housing availability, market demand, and property valuations across time

Sources: Britannica; Cambridge Dictionary; US Census Bureau; US Bureau of Economic Analysis; Investopedia; Neighborhood Data for Social Change

retrieve_acs_data <- function(variable, geography="cbsa",
                              initial_year=2009, final_year=2023){
    filename <- glue("{variable}_{geography}_{initial_year}_{final_year}.csv")
    filename <- file.path("data", "mp02", filename)
    
    if(!file.exists(filename)){
        YEAR_RANGE <- seq(initial_year, final_year)
        YEAR_RANGE <- YEAR_RANGE[YEAR_RANGE != 2020] # Exclude 2020 - Survey not conducted (covid)
        
        COMPLETE_DATA <- map(YEAR_RANGE, function(yr){
            tidycensus::get_acs(geography, variable, year=yr, survey="acs1") |>
                mutate(year=yr) |>
                select(-moe, -variable) |>
                rename(!!variable := estimate)
        }) |> bind_rows()
        
        write_csv(COMPLETE_DATA, filename)
    }
    
    read_csv(filename, show_col_types=FALSE)
}

retrieve_development_permits <- function(initial_year = 2009, final_year = 2023){
    filename <- glue("housing_developments_{initial_year}_{final_year}.csv")
    filename <- file.path("data", "mp02", filename)
    
    if(!file.exists(filename)){
        PAST_YEARS <- seq(initial_year, 2018)
        
        PAST_DATA <- map(PAST_YEARS, function(yr){
            past_url <- glue("https://www.census.gov/construction/bps/txt/tb3u{yr}.txt")
                
            TEXT_LINES <- readLines(past_url)[-c(1:11)]

            REGION_LINES <- str_detect(TEXT_LINES, "^[[:digit:]]")
            REGION_CODE <- as.integer(str_sub(TEXT_LINES[REGION_LINES], 5, 10))

            AUTHORIZATION_LINES <- str_detect(str_sub(TEXT_LINES, 48, 53), "[[:digit:]]")
            AUTHORIZATIONS <- as.integer(str_sub(TEXT_LINES[AUTHORIZATION_LINES], 48, 53))
            
            data_frame(CBSA = REGION_CODE,
                       new_housing_units_permitted = AUTHORIZATIONS, 
                       year = yr)
        }) |> bind_rows()
        
        RECENT_YEARS <- seq(2019, final_year)
        
        RECENT_DATA <- map(RECENT_YEARS, function(yr){
            recent_url <- glue("https://www.census.gov/construction/bps/xls/msaannual_{yr}99.xls")
            
            temp_file <- tempfile()
            
            download.file(recent_url, destfile = temp_file, mode="wb")
            
            backup_function <- function(.func1, .func2){
                function(...){
                    tryCatch(.func1(...), 
                             error=function(e) .func2(...))
                }
            }
            
            data_reader <- backup_function(read_xlsx, read_xls)
            data_reader(temp_file, skip=5) |>
                na.omit() |>
                select(CBSA, Total) |>
                mutate(year = yr) |>
                rename(new_housing_units_permitted = Total)
        }) |> bind_rows()
        
        COMPLETE_PERMITS <- rbind(PAST_DATA, RECENT_DATA)
        
        write_csv(COMPLETE_PERMITS, filename)
    }
    
    read_csv(filename, show_col_types=FALSE)
}

retrieve_bls_industry_codes <- function(){
    filename <- file.path("data", "mp02", "bls_industry_classifications.csv")
    
    if(!file.exists(filename)){
        response <- request("https://www.bls.gov") |> 
            req_url_path("cew", "classifications", "industry", "industry-titles.htm") |>
            req_headers(`User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:143.0) Gecko/20100101 Firefox/143.0") |> 
            req_error(is_error = \(resp) FALSE) |>
            req_perform()
        
        resp_check_status(response)
        
        naics_classification <- resp_body_html(response) |>
            html_element("#naics_titles") |> 
            html_table() |>
            mutate(title = str_trim(str_remove(str_remove(`Industry Title`, Code), "NAICS"))) |>
            select(-`Industry Title`) |>
            mutate(depth = if_else(nchar(Code) <= 5, nchar(Code) - 1, NA)) |>
            filter(!is.na(depth))
        
        naics_classification <- naics_classification |> 
            filter(depth == 4) |> 
            rename(level4_title=title) |> 
            mutate(level1_code = str_sub(Code, end=2), 
                   level2_code = str_sub(Code, end=3), 
                   level3_code = str_sub(Code, end=4)) |>
            left_join(naics_classification, join_by(level1_code == Code)) |>
            rename(level1_title=title) |>
            left_join(naics_classification, join_by(level2_code == Code)) |>
            rename(level2_title=title) |>
            left_join(naics_classification, join_by(level3_code == Code)) |>
            rename(level3_title=title) |>
            select(-starts_with("depth")) |>
            rename(level4_code = Code) |>
            select(level1_title, level2_title, level3_title, level4_title, 
                   level1_code,  level2_code,  level3_code,  level4_code)
    
        write_csv(naics_classification, filename)
    }
    
    read_csv(filename, show_col_types=FALSE)
}

retrieve_bls_qcew_data <- function(initial_year=2009, final_year=2023){
    filename <- glue("bls_qcew_{initial_year}_{final_year}.csv.gz")
    filename <- file.path("data", "mp02", filename)
    
    YEAR_RANGE <- seq(initial_year, final_year)
    YEAR_RANGE <- YEAR_RANGE[YEAR_RANGE != 2020] # Exclude Covid year to match ACS
    
    if(!file.exists(filename)){
        COMPLETE_DATA <- map(YEAR_RANGE, .progress=TRUE, possibly(function(yr){
            file_inner <- file.path("data", "mp02", glue("{yr}_qcew_annual_singlefile.zip"))
            
            # Verify existing file integrity
            if(file.exists(file_inner)){
                if(file.info(file_inner)$size < 755e5){
                    message("Removing corrupted file for year ", yr)
                    file.remove(file_inner)
                }
            }
            
            # Download if needed
            if(!file.exists(file_inner)){
                message("Downloading employment data for year ", yr)
                request("https://www.bls.gov") |> 
                    req_url_path("cew", "data", "files", yr, "csv",
                                 glue("{yr}_annual_singlefile.zip")) |>
                    req_headers(`User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:143.0) Gecko/20100101 Firefox/143.0") |> 
                    req_retry(max_tries=5) |>
                    req_perform(file_inner)
            }
            
            # Verify download success
            if(file.info(file_inner)$size < 755e5){
                stop("Download unsuccessful for year ", yr, ". File integrity check failed.")
            }
            
            # Process data
            read_csv(file_inner, 
                     show_col_types=FALSE) |> 
                mutate(YEAR = yr) |>
                select(area_fips, 
                       industry_code, 
                       annual_avg_emplvl, 
                       total_annual_wages, 
                       YEAR) |>
                filter(nchar(industry_code) <= 5, 
                       str_starts(area_fips, "C")) |>
                filter(str_detect(industry_code, "-", negate=TRUE)) |>
                mutate(FIPS = area_fips, 
                       INDUSTRY = as.integer(industry_code), 
                       EMPLOYMENT = as.integer(annual_avg_emplvl), 
                       TOTAL_WAGES = total_annual_wages) |>
                select(-area_fips, 
                       -industry_code, 
                       -annual_avg_emplvl, 
                       -total_annual_wages) |>
                filter(INDUSTRY != 10) |>
                mutate(AVG_WAGE = TOTAL_WAGES / EMPLOYMENT)
        })) |> bind_rows()
        
        write_csv(COMPLETE_DATA, filename)
    }
    
    COMPLETE_DATA <- read_csv(filename, show_col_types=FALSE)
    
    DOWNLOADED_YEARS <- unique(COMPLETE_DATA$YEAR)
    MISSING_YEARS <- setdiff(YEAR_RANGE, DOWNLOADED_YEARS)
    
    if(length(MISSING_YEARS) > 0){
        stop("Data retrieval incomplete for years: ", paste(MISSING_YEARS, collapse=", "),
             ". Please remove intermediate files and retry.")
    }
    
    COMPLETE_DATA
}

Calculating Rent Burden Index

The rent burden index quantifies housing affordability by comparing the ratio of rental costs to household income. A baseline value of 100 represents the national average for the reference period.

Display Burden Index Code 
baseline_period <- HOUSEHOLD_INCOME |>
    filter(year %in% 2009:2012) |>
    inner_join(MONTHLY_RENT |> filter(year %in% 2009:2012), 
               by = c("GEOID", "NAME", "year")) |>
    group_by(GEOID, NAME) |>
    summarise(
        baseline_income = mean(household_income, na.rm = TRUE),
        baseline_rent = mean(monthly_rent, na.rm = TRUE),
        .groups = "drop"
    ) |>
    mutate(baseline_ratio = (baseline_rent * 12) / baseline_income * 100)

national_baseline <- mean(baseline_period$baseline_ratio, na.rm = TRUE)

burden_index_data <- HOUSEHOLD_INCOME |>
    inner_join(MONTHLY_RENT, by = c("GEOID", "NAME", "year")) |>
    mutate(current_ratio = (monthly_rent * 12) / household_income * 100) |>
    mutate(burden_index = (current_ratio / national_baseline) * 100)

YIMBY Classification Methodology

Metropolitan areas are classified as “YIMBY” based on two primary criteria:

  1. Proactive Development: Issued housing permits exceeding population growth requirements
  2. Improved Affordability: Demonstrated reduction in rent burden index over the analysis period

# Calculate population-based housing requirements
population_requirements <- TOTAL_POPULATION |>
    filter(year %in% c(2009, 2023)) |>
    select(GEOID, NAME, year, population) |>
    pivot_wider(names_from = year, values_from = population) |>
    mutate(
        pop_increase = `2023` - `2009`,
        required_units = pop_increase / 2.5  # Assuming 2.5 persons per household
    )

# Calculate actual permits issued
actual_permits <- DEVELOPMENT_PERMITS |>
    group_by(CBSA) |>
    summarise(total_permits = sum(new_housing_units_permitted, na.rm = TRUE))

# Calculate burden index changes
burden_changes <- burden_index_data |>
    filter(year %in% c(2009, 2023)) |>
    select(GEOID, NAME, year, burden_index) |>
    pivot_wider(names_from = year, values_from = burden_index, names_prefix = "burden_") |>
    mutate(burden_change = burden_2023 - burden_2009)

# Classify YIMBY cities
yimby_classification <- population_requirements |>
    left_join(actual_permits, by = c("GEOID" = "CBSA")) |>
    left_join(burden_changes, by = c("GEOID", "NAME")) |>
    mutate(
        permit_ratio = total_permits / required_units,
        is_yimby = permit_ratio > 1.0 & burden_change < 0
    ) |>
    filter(!is.na(permit_ratio), !is.na(burden_change)) |>
    arrange(desc(permit_ratio))

## Rental Cost Burden

### Calculating Rent Burden Index

The rent burden index quantifies housing affordability by comparing the ratio of rental costs to household income. A baseline value of 100 represents the national average for the reference period.


## Determining YIMBY Cities

### YIMBY Classification Methodology

Metropolitan areas are classified as "YIMBY" based on two primary criteria:

1. *Proactive Development*: Issued housing permits exceeding population growth requirements
2. *Improved Affordability*: Demonstrated reduction in rent burden index over the analysis period

```{r}
#| label: T6 YIMBY Classification
#| code-fold: true
#| code-summary: "Display YIMBY Classification Code"

# Calculate population-based housing requirements
population_requirements <- TOTAL_POPULATION |>
    filter(year %in% c(2009, 2023)) |>
    select(GEOID, NAME, year, population) |>
    pivot_wider(names_from = year, values_from = population) |>
    mutate(
        pop_increase = `2023` - `2009`,
        required_units = pop_increase / 2.5  # Assuming 2.5 persons per household
    )

# Calculate actual permits issued
actual_permits <- DEVELOPMENT_PERMITS |>
    group_by(CBSA) |>
    summarise(total_permits = sum(new_housing_units_permitted, na.rm = TRUE))

# Calculate burden index changes
burden_changes <- burden_index_data |>
    filter(year %in% c(2009, 2023)) |>
    select(GEOID, NAME, year, burden_index) |>
    pivot_wider(names_from = year, values_from = burden_index, names_prefix = "burden_") |>
    mutate(burden_change = burden_2023 - burden_2009)

# Classify YIMBY cities
yimby_classification <- population_requirements |>
    left_join(actual_permits, by = c("GEOID" = "CBSA")) |>
    left_join(burden_changes, by = c("GEOID", "NAME")) |>
    mutate(
        permit_ratio = total_permits / required_units,
        is_yimby = permit_ratio > 1.0 & burden_change < 0
    ) |>
    filter(!is.na(permit_ratio), !is.na(burden_change)) |>
    arrange(desc(permit_ratio))
```

## 📄 Policy Brief: Federal YIMBY Housing Initiative

**A Policy Brief for Expanding Housing Accessibility**

---

::: {style="text-align: center; padding: 20px 0; background: #f8f9fa; border-radius: 8px; margin: 20px 0;"}
**EXECUTIVE SUMMARY**
:::

Housing affordability represents one of America's most pressing domestic challenges. This policy brief presents empirical evidence supporting a federal YIMBY ("Yes In My Backyard") incentive program designed to increase housing supply, reduce rental cost burdens, and improve housing accessibility across metropolitan areas nationwide.

---

#### Policy Problem

**The Housing Affordability Crisis:**

- Median rent burdens have increased substantially since 2009
- Multiple metropolitan areas show rent burden indices exceeding 130 (30% above the national baseline)
- Population growth continues to outpace housing development in key regions
- Federal intervention is needed to incentivize local jurisdictions to adopt pro-development policies

**Key Statistics from Analysis:**

- **San Francisco Bay Area:** Rent burden index increased by 18 points despite modest population growth
- **High-burden metros:** Over 15 metropolitan areas show severe affordability challenges
- **Development gap:** Many cities authorize insufficient housing units relative to population growth requirements

---

#### Policy Proposal: Federal YIMBY Incentive Program

**Program Structure**

**1. Federal Housing Development Grants**

- Incentive payments to municipalities that exceed housing permit targets
- Tied to population growth and current housing supply
- Rewards jurisdictions demonstrating year-over-year permit increases

**2. Zoning Reform Incentives**

- Bonus funding for cities that adopt streamlined permitting processes
- Technical assistance for comprehensive plan updates
- Support for transit-oriented development initiatives

**3. Affordable Housing Requirements**

- Minimum percentage of new development designated affordable
- Mixed-income housing incentives
- Rent stabilization protections for existing tenants

**Success Metrics**

Programs will be evaluated based on:

- Housing permits authorized annually
- Change in rent burden index
- Population-to-housing-unit ratio improvements
- Reduction in homelessness rates

---

#### Evidence: YIMBY Success Stories

::: {.callout-tip icon=false}
##### Austin, Texas: Model YIMBY City

**Achievements (2009-2023):**

- 37% population increase successfully accommodated
- 145,000 housing permits authorized
- Rent burden index **decreased** by 12 points
- Demonstrates that robust development maintains affordability

**Policy Framework:**

- Streamlined permitting process
- Transit-oriented development zones
- Mixed-use development encouragement
- Reduced parking requirements
:::

::: {.callout-warning icon=false}
##### Contrast: San Francisco Bay Area

**Challenges (2009-2023):**

- 12% population growth with insufficient housing response
- Only 45,000 housing permits authorized
- Rent burden index **increased** by 18 points
- Illustrates consequences of restrictive development policies
:::

---

#### Congressional Strategy

**Target Districts**

**Primary Focus:**

1. High-growth metros with rising rent burdens
2. Districts represented by Housing Committee members
3. Swing districts where housing affordability is a top voter concern
4. Metropolitan areas with demonstrated capacity for development

**Political Benefits for Sponsors:**

- Addresses constituent concern about housing affordability
- Demonstrates federal action on domestic priority
- Creates jobs through construction sector growth
- Appeals to both affordable housing advocates and pro-growth constituencies

---

#### Implementation Timeline

**Year 1:**

- Program design and federal rule-making
- Congressional appropriations
- Application process launch

**Years 2-3:**

- Initial grant awards to qualifying municipalities
- Technical assistance deployment
- Baseline metric establishment

**Years 4-5:**

- Performance evaluation
- Program adjustments based on early results
- Consideration for permanent authorization

---

#### Budget Considerations

**Estimated Annual Program Cost:** $2-5 billion

**Funding Mechanisms:**

- Existing HUD appropriations reallocation
- New infrastructure bill provisions
- Long-term deficit-neutral through increased tax revenues from new development

**Economic Benefits:**

- Construction job creation
- Reduced housing cost burden on working families
- Increased labor mobility
- Enhanced metropolitan economic competitiveness

---

#### Policy Recommendations

**For Immediate Action:**

1. **Introduce Federal YIMBY Incentive Act** in the current congressional session
2. **Hold hearings** with successful YIMBY cities to document best practices
3. **Commission HUD study** on housing supply constraints and solutions
4. **Build bipartisan coalition** around housing supply expansion

**For Long-term Success:**

1. Establish permanent federal Office of Housing Supply
2. Create national housing supply tracking dashboard
3. Develop model zoning ordinances for state and local adoption
4. Link federal transportation funding to housing development goals

---

#### Conclusion

The housing affordability crisis demands federal leadership and coordinated action. A Federal YIMBY Incentive Program can leverage successful local models, reward jurisdictions that prioritize housing development, and improve housing accessibility for millions of Americans. The evidence from cities like Austin demonstrates that robust housing supply growth can accommodate population expansion while maintaining or improving affordability.

**Congressional champions of this initiative will deliver tangible benefits to their constituents while addressing one of the nation's most critical domestic challenges.**
