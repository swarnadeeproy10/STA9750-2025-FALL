Introduction

This project examines the current tree species distribution across New York City’s 51 City Council districts to develop a data-informed proposal for a new parks initiative. Through comprehensive spatial and health analysis of NYC’s urban forest, this study identifies strategic opportunities to maximize public health benefits through evidence-based tree species selection.

NoteProject Description

From the STA 9750 Course Assignment Page:

“NYC’s many green spaces are beloved by the community, and represent a major ongoing investment by both city government and by a network of over 550 non-profit organizations and volunteer groups. With a budget of over $675,000,000 and over 5,000 full-time employees, the Department of Parks and Recreation (DPR) maintains over 30,000 acres of public parkland. DPR is also responsible for almost 900,000 trees, representing over 500 different species, across the city. In this mini-project, we will explore the NYC TreeMap data set, with an eye towards creating compelling visualizations of this beloved element of NYC’s urban fabric. Based on these visualizations, you will propose a new program for the NYC Parks Department that attempts to make the benefits of NYC trees available to all New Yorkers.”

download_districts <- function() {
  geojson_file <- file.path(data_dir, "districts.geojson")
  
  if (file.exists(geojson_file)) {
    message("Reading cached districts...")
    districts <- st_read(geojson_file, quiet = TRUE)
    districts <- st_transform(districts, 4326)
    return(districts)
  }
  
  # Try multiple data sources
  urls <- c(
    "https://data.cityofnewyork.us/api/geospatial/yusd-j4xi?method=export&format=GeoJSON",
    "https://services5.arcgis.com/GfwWNkhOj9bNBqoJ/arcgis/rest/services/NYC_City_Council_Districts/FeatureServer/0/query?where=1=1&outFields=*&outSR=4326&f=geojson"
  )
  
  for (url in urls) {
    message("Attempting download from: ", substring(url, 1, 60), "...")
    districts <- tryCatch(st_read(url, quiet = TRUE), error = function(e) NULL)
    
    if (!is.null(districts) && nrow(districts) > 0) {
      message("✓ Successfully downloaded ", nrow(districts), " districts")
      districts <- st_transform(districts, 4326)
      st_write(districts, geojson_file, quiet = TRUE)
      return(districts)
    }
  }
  
  stop("Could not download district boundaries from any source")
}

download_trees <- function() {
  all_trees <- list()
  
  # Try multiple NYC Open Data endpoints
  base_urls <- c(
    "https://data.cityofnewyork.us/resource/5rq2-4hqu.geojson",  # 2015 Census
    "https://data.cityofnewyork.us/resource/nwxe-4ae8.geojson"   # Alternative
  )
  
  for (base_url in base_urls) {
    message("\n=== Attempting tree data download from ===")
    message(base_url)
    
    for (batch in 0:19) {  # Download up to 1 million trees (20 batches × 50k)
      offset <- batch * 50000
      file <- file.path(data_dir, paste0("trees_", offset, ".geojson"))
      
      if (file.exists(file)) {
        message("  Batch ", batch, ": Reading from cache...")
        trees <- st_read(file, quiet = TRUE)
        if (st_crs(trees)$input != "EPSG:4326") {
          trees <- st_transform(trees, 4326)
        }
      } else {
        message("  Batch ", batch, ": Downloading...")
        url <- paste0(base_url, "?$limit=50000&$offset=", offset)
        
        trees <- tryCatch({
          downloaded <- st_read(url, quiet = TRUE)
          st_transform(downloaded, 4326)
        }, error = function(e) {
          message("    Error: ", e$message)
          return(NULL)
        })
        
        if (!is.null(trees) && nrow(trees) > 0) {
          st_write(trees, file, quiet = TRUE)
          message("    ✓ Saved ", nrow(trees), " trees")
        }
      }
      
      if (is.null(trees) || nrow(trees) == 0) {
        message("  No more data in this batch")
        break
      }
      
      all_trees[[batch + 1]] <- trees
      message("    Total so far: ", format(sum(sapply(all_trees, nrow)), big.mark = ","))
      
      if (nrow(trees) < 50000) {
        message("  Received final batch")
        break
      }
    }
    
    if (length(all_trees) > 0) {
      message("\n✓ Download complete from this source")
      break
    }
  }
  
  if (length(all_trees) == 0) {
    stop("Could not download tree data from any source")
  }
  
  message("\nCombining all batches...")
  do.call(rbind, all_trees)
}

Project Proposal: Strategic Tree Replacement Program

Transforming Routine Maintenance into Public Health Intervention

ImportantExecutive Summary

Prepared for: NYC City Council & NYC Department of Parks and Recreation
Issue: Dead tree replacement presents opportunity to reduce respiratory disease burden
Proposal: Replace dead trees with health-optimized species
Location: Priority Council District
Investment: Within existing maintenance budget
Timeline: 18-month implementation + 3-year monitoring
Impact: Measurable reduction in respiratory health burden for residents

The Problem: Trees That Harm Public Health

While NYC’s urban forest provides immense benefits, not all tree species are created equal for public health:

High-Isoprene Emitting Species (pin oak, red oak, sweetgum): - Emit volatile organic compounds (VOCs) that react with NOₓ to form ground-level ozone - Contribute to summer smog formation - Exacerbate asthma and respiratory conditions - Particularly problematic in hot weather

Allergen-Producing Species (certain oaks, maples): - High pollen production - Extended allergy seasons - Increased burden on respiratory health - Disproportionate impact on children and elderly

The Opportunity: Strategic Species Selection

Replace dead trees with climate-appropriate, health-beneficial species:

Recommended Species Mix:

  1. Ginkgo (40% of replacements)
    • Zero isoprene emissions
    • Low allergen potential
    • Exceptional urban tolerance
    • Beautiful fall color
    • Long-lived (>200 years)
  2. Honeylocust (35% of replacements)
    • Minimal VOC emissions
    • Light, filtered shade
    • Tolerates compacted soil
    • Drought resistant
    • Low maintenance
  3. Japanese Zelkova (25% of replacements)
    • Low allergen production
    • Disease resistant
    • Excellent structure
    • Adapts to various conditions
    • Proven NYC performer

Why Three Species? - Prevents monoculture vulnerability - Different bloom/leaf-out times - Varied mature heights and forms - Aesthetic diversity - Risk mitigation (pests, disease, climate)

Implementation Plan

NoteThree-Phase Approach

Phase 1 (Months 1-6): Dead Tree Removal & Site Prep - Remove all dead trees - Assess and improve planting sites - Test soil conditions - Community engagement and education

Phase 2 (Months 7-12): Primary Planting - Plant 70% of replacement trees - Focus on high-visibility areas first - Ensure species distribution mix - Install monitoring equipment

Phase 3 (Months 13-18): Completion & Establishment - Complete remaining 30% of plantings - Intensive watering and care - Community tree steward training - Begin health outcome tracking

Conclusion

Summary of Findings

This comprehensive analysis of NYC’s street tree data reveals a significant opportunity to enhance public health through strategic tree species selection.

Key Recommendations

ImportantPrimary Recommendation

Adopt health-based species selection criteria for all dead tree replacements citywide.

This transforms routine maintenance expenditure into a public health intervention with measurable outcomes.

Supporting Actions:

  1. Implement three-phase replacement strategy
  2. Monitor health outcomes (air quality, ED visits) for 3 years
  3. Document cost-benefit outcomes
  4. Expand successful model to additional high-need districts
  5. Integrate health criteria into NYC Parks tree selection guidelines

Data Sources & Methodology

Primary Data Sources

Spatial Data: - NYC Street Tree Census (2015), NYC Parks Department - NYC Council District Boundaries, Department of City Planning - Tree locations via point geometry (WGS84/EPSG:4326)

Analytical Methods

Spatial Analysis: - Point-in-polygon spatial join (sf package, R 4.3+) - Coordinate system: WGS84 (EPSG:4326) - Geometry validation and cleaning

Classification Criteria: - Isoprene emissions: >10 μg C g⁻¹ h⁻¹ = “High” - Based on Benjamin et al. (1996), Geron et al. (2001) - Tree health: NYC Parks arborist assessments

  • Health assessments point-in-time
  • Some trees may have been removed/replaced
  • Weather and climate variations affect health outcomes
  • Correlation vs. causation in health benefits
